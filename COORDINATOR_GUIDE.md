# Coordinator Guide: Uploading AACCUP Evidence

This guide is for **area coordinators**. You only need Google Drive and the website. You never need to open the Google Sheet.

## 1. Log in

1. Open the portal website and type the **6-digit coordinator PIN** (all coordinators share the same one). It logs you in as soon as you type the 6th digit.
2. On the program's card, choose **Compliance Report** or **PPP** (then an area card), or **Self-Survey Report and Evidences** (then the Actual Self-Survey Report or an area).
3. The screen now shows the folders on the **left** (for an area: Parameters › Indicators › files) and the selected item on the **right**.
   - **⌂ Home** goes back to the programs; the **▦** button goes back to the card page you came from.
   - The **Program ▾** and **Area ▾** menus at the top switch directly.
   - On a phone, tap **☰ Files** to show the list.

As a coordinator you can open **every program and every area**, including files uploaded by other coordinators. Indicators with no documents yet have a red **●** in the list.

Keep the coordinator PIN within the coordinator team. Never give it to accreditors: they have their own PINs, which only let them view.

## 2. Upload to the right folder

**Easiest way: from the website**

1. In the list on the left, find the indicator you want (for example **S.1**), or the subfolder inside it
   (for example **S.5 › S.5.1. Technical skills**).
2. Tap the **＋** at the right end of that row. That exact Google Drive folder opens in a new tab.
   Make sure you are signed in to Google with the account Ariel gave access to.
3. Drag your files into the folder, or click **New → File upload**. Wait until Drive says the upload is complete.
4. Go back to the website tab and tap **↻ Check now**. Your files appear within a few seconds.
   (Without Check now, they still appear by themselves within about **5 minutes**.)

**Or directly in Drive:** open the program folder (link from Ariel) → the **Area** → the **Parameter** → the **indicator** folder, and upload there.

✅ Evidence for an indicator goes **inside that indicator folder** (S.1, S.2, I.1, O.1 …).
📄 A file put directly in a Parameter or Area folder is shown to everyone under **General documents** at the top of that parameter or area.
📋 **Compliance Report and PPP:** folders in the program folder, next to the Area folders, with one subfolder per area inside (e.g. `Compliance Report › Area 02 - Faculty`). Whatever you put in an area subfolder is shown as it is.
📘 **Actual Self-Survey Report:** a folder with that name in the program folder, holding the report document(s).
📥 **Requested Documents:** made automatically in the program folder, with one folder per accreditor inside, for documents accreditors asked for (see section 5).
Other files left in the program folder show as **Other documents**.

If one document is evidence for two indicators, upload it once. Then, in the second folder, right-click → **Add shortcut** to point to it.

## 3. Name files clearly

Accreditors search by file name, so make names say what the document is:

| ✅ Good | ❌ Avoid |
|---|---|
| `Board Resolution No. 45, s. 2023 - Approval of VMGO.pdf` | `scan0012.pdf` |
| `Faculty Profile AY 2025-2026.xlsx` | `final final v2.xlsx` |
| `Minutes of Faculty Meeting - Oct 2025.pdf` | `IMG_2034.jpg` |

## 4. Add keywords (optional, but very helpful)

Keywords help accreditors find a file even when its name doesn't contain the word they search for.

1. Click an indicator in the list on the left. Its files are listed on the right.
2. Tap **✎ Keywords** under a file and type keywords separated by **commas**, for example `BOR, approval, resolution, 2023`.
3. Tap **Save**. "✓ Saved" means it worked.

You can add keywords to any file in any area.

## 5. Requested Documents (when an accreditor asks for something)

Accreditors don't request documents in the website. They ask you in person or by message. You answer by putting the document in **that accreditor's folder** inside **Requested Documents**. **Only that accreditor can see it.**

```
Requested Documents/
  Dr. Reyes/      ← only Dr. Reyes sees what is in here
  Dr. Cruz/       ← only Dr. Cruz sees what is in here
```

The folders are made automatically, one per accreditor, the first time someone opens Requested Documents on the website. You never need to create or rename them.

**Step by step**

1. On the program's card, tap **Requested Documents**.
2. Tap the accreditor who asked, e.g. **Dr. Reyes**.
3. Tap **＋ Add files for Dr. Reyes**. Their folder opens in Google Drive. Drag the document(s) in, or click **New → File upload**. Wait until Drive says the upload is complete.
4. Go back to the website tab and tap **↻ Refresh**. It says **"✓ Updated: 1 new"**. If it says "No new files yet", wait a moment and tap it again.
   (Without Refresh, the file still appears by itself within about **5 minutes**.)
5. *Optional:* tap the file, then **✎ Details**. Type a short **description** for the accreditor (e.g. *"Faculty teaching load, AY 2025-2026, as asked on Dec 1"*) and tap **Save**.

**Good to know**

- You may also go straight to Google Drive, open **Requested Documents › Dr. Reyes**, and upload there. It works the same.
- **Two accreditors asked for the same document?** Put it in one person's folder, then in **✎ Details** tick the other person under **Also show to**.
- **To take a document back**, delete it from the folder in Google Drive, then tap **↻ Refresh**.
- A file put directly in **Requested Documents** (not inside a name folder) shows under **⚠ Not assigned**, and no accreditor sees it. Move it into the right name folder, or tick a name in **✎ Details**.
- If a folder shows **⚠ Not an accreditor name**, its name doesn't match anyone in the accreditor list (for example a typo). No accreditor sees its files until it is renamed in Drive.
- The accreditor sees a **Requested Documents** tile on their program card, with **● New** until they open the file, and the description under the file name. If they are already logged in, a message tells them it has arrived.
- Subfolders inside a name folder are fine (e.g. one per area). Accreditors never see other accreditors' folders or names.
- After the visit, you can copy the documents into the right indicator folders so the evidence stays complete.

## 6. See every file in one list

Tap **≡ All files** in the bar at the top (or on the Home page). It lists every file of **both programs** in one place, so you don't have to open each folder.

- Type in the **filter** box to narrow the list by file name, keyword, area, parameter or indicator. The menus narrow it by **program**, **section** (Compliance Report, PPP, Self-Survey Report, Area I … X), and **file type**, and change the **order** (folder order, name, newest first).
- Tap a file to open it **beside the list**. On a phone it fills the screen; tap **Show files** to get the list back.
- **📁↗** on a row (or **📁 Open folder in Drive** above the open file) opens the Google Drive folder that file is in.
- **✎ Keywords** above the open file works the same as in the area pages.
- **Requested Documents** files are listed here too (section menu: Requested Documents). Descriptions and "Also show to" are set on the program's Requested Documents page.
- Older reference material, such as **Previous Accre Docs**, is listed here too. Pick it in the **section** menu (it starts with "Reference:"). These files appear only in this list, not in the top search box or on the area cards.

Only coordinators and the admin see this list. Accreditors don't.

## 7. Please do NOT

- ❌ Rename, move or delete **folders**. The website relies on them.
- ❌ Create your own Area, Parameter or indicator folders. Ask Ariel instead.
- ❌ Create your own subfolders inside indicator folders. Sub-indicator folders that already exist (e.g. **I.1.6.1 › I.1.6.1.3. Students**) are fine to upload into.
- ❌ Upload anything confidential. Everything here can be opened by anyone with the link.

If you uploaded something to the wrong place, tell Ariel. Moving files is easy.

## 8. Make scanned PDFs smaller

Large scans load slowly for accreditors. Aim for **under 20 MB** per file.

- Scan at **150–200 dpi**, in **grayscale** if color isn't needed.
- Compress before uploading with a free online tool, e.g. **iLovePDF → Compress PDF** or **Adobe Acrobat online → Compress PDF** (choose "Recommended" or "Medium").
- Split very long documents into logical parts (e.g. per semester).
